Installers are verified with Elyra's embedded Ed25519 public key before installation. On Windows, the app closes while the installer runs.

Behaviour

When automatic suggestions are off, new mail starts at this level. Refreshing recomputes automatic priorities without changing messages you set yourself.

Senders & domains

Blocked senders are filtered automatically. Allow rules always win, so a trusted address or domain is never blocked.

Attachment security

Elyra identifies attachments from their real file content and never opens or runs them automatically. Local analysis stays on this device.

Mail accounts

Elyra Cloud
Local-only — connect Elyra Cloud for notifications

Point the desktop app at your Elyra server. Leave blank to use the built-in default. Changes apply to the next sign-in, mail relay and notification request.

Sync & offline

Messages stay readable from the local cache. If sending fails, Elyra keeps the message in an outbox and retries when you ask it to.

Checking sync status…

Queued messages are stored locally; nothing leaves the device until the outbox is flushed.

Diagnostics & privacy

Logs are stored on this device, redacted before they are saved, and rotated automatically. Nothing is uploaded automatically.

Local data

Appearance changes save immediately. Identity and behaviour changes save when you press Save changes. Sender rules save as you add them.
