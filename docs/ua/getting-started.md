# Початок роботи

Ця сторінка проведе вас від комп’ютера з чистою системою Windows до працюючої поштової скриньки Elyra.

Elyra 0.4.0 — це десктопний застосунок для Windows. Він працює повністю на
вашому комп’ютері, якщо ви явно не під’єднаєте Elyra Cloud. Для пробного
використання локальної поштової скриньки обліковий запис не потрібен.

## 1. Перевірте вимоги

| Вимога | Деталі |
| --- | --- |
| Операційна система | Windows 10 або Windows 11, 64-бітна |
| Архітектура | x64 (`x86_64`) |
| Диск | Приблизно 100 МБ для застосунку плюс база даних локальної поштової скриньки |
| Мережа | Необов’язкова. Потрібна для синхронізації IMAP, Elyra Cloud, оновлень і серверного ретранслятора пошти |
| Права адміністратора | Не потрібні для інсталятора NSIS на одного користувача. MSI може вимагати підвищення прав, оскільки є пакетом для всього комп’ютера |

Збірки для macOS не публікуються. Пакети Linux `x86_64` AppImage та `.deb`
збираються окремим робочим процесом випуску; див. [Linux](linux.md) щодо
встановлення та відомих обмежень. Підтримка лаунчера є лише у варіанті для
Windows.

## 2. Виберіть інсталятор

Завантажте його з [останнього випуску](https://github.com/imtiredwhenitalk/Elyra/releases/latest).

| Файл | Найкраще підходить для | Поведінка |
| --- | --- | --- |
| `Elyra-latest-x64.msi` | Керовані комп’ютери, стандартне розгортання через Windows Installer | Встановлення для всього комп’ютера, може вимагати підтвердження адміністратора |
| `Elyra-latest-x64-setup.exe` | Звичайне особисте встановлення | Інсталятор NSIS з режимом встановлення для одного користувача |
| `Elyra-Launcher-x64.exe` | Користувачі, яким потрібне найменше завантаження та автоматичні оновлення | Завантажує MSI з відновленням і повторними спробами, перевіряє його, встановлює та відкриває Elyra |
| `Elyra-latest-x64.msi.sha256` | Перевірка цілісності | SHA-256-геш MSI |

Усі файли випуску мають стабільні імена, щоб посилання продовжували працювати
між версіями. Версію можна побачити в **Налаштування → Діагностика** та в назві
випуску GitHub.

### Перевірка завантаження вручну

У PowerShell:

```powershell
Get-FileHash .\Elyra-latest-x64.msi -Algorithm SHA256
Get-Content .\Elyra-latest-x64.msi.sha256
```

Обидва геші мають збігатися. Якщо вони не збігаються, видаліть файл і
завантажте його знову. Не запускайте інсталятор, контрольна сума якого не
збігається.

## 3. Встановлення

### Варіант A: інсталятор NSIS (рекомендується більшості користувачів)

1. Запустіть `Elyra-latest-x64-setup.exe`.
2. Дотримуйтесь інструкцій майстра. Встановлення для одного користувача не
   потребує прав адміністратора.
3. Запустіть Elyra через меню «Пуск» або ярлик на робочому столі.

### Варіант B: пакет MSI

1. Запустіть `Elyra-latest-x64.msi`.
2. Підтвердьте запит Windows Installer на підвищення прав, якщо він з’явиться.
3. Запустіть Elyra через меню «Пуск».

<a id="option-c-portable-launcher"></a>
### Варіант C: портативний лаунчер

Лаунчер — це один виконуваний файл. Якщо запустити його без аргументів, він
завантажить `Elyra-latest-x64.msi` з останнього випуску GitHub, перевірить
магічні байти MSI, перевірить опублікований супутній файл `.sha256`, запустить
Windows Installer і відкриє застосунок. Завантаження записуються у файл `.part`,
відновлюються після переривання передачі, повторюються при тимчасових помилках
і лише після перевірки отримують остаточну назву MSI. Уже перевірений MSI з кешу
використовується повторно.

```powershell
.\Elyra-Launcher-x64.exe
```

Корисні команди та прапорці:

| Команда | Призначення |
| --- | --- |
| `Elyra-Launcher-x64.exe` | Встановити або оновити, а потім запустити |
| `Elyra-Launcher-x64.exe install` | Те саме, що й без аргументів |
| `Elyra-Launcher-x64.exe update` | Псевдонім команди install |
| `Elyra-Launcher-x64.exe download` | Завантажити й перевірити інсталятор без встановлення |
| `Elyra-Launcher-x64.exe launch` | Відкрити вже встановлену Elyra |
| `Elyra-Launcher-x64.exe info` | Показати версії, шляхи, запис про встановлення та теку завантажень |
| `Elyra-Launcher-x64.exe cleanup` | Видалити застарілі завантажені інсталятори |
| `Elyra-Launcher-x64.exe uninstall` | Видалити Elyra, але зберегти базу даних локальної поштової скриньки |
| `Elyra-Launcher-x64.exe --msi <path>` | Встановити локальний MSI замість завантаження |
| `Elyra-Launcher-x64.exe --url <url>` | Завантажити з власної HTTPS-адреси |
| `Elyra-Launcher-x64.exe --sha256 <digest>` | Вимагати певну контрольну суму |
| `Elyra-Launcher-x64.exe --require-checksum` | Відмовлятися встановлювати, якщо контрольну суму не опубліковано |
| `Elyra-Launcher-x64.exe --retries <n>` | Кількість спроб завантаження, 0–10 (типово: 3) |
| `Elyra-Launcher-x64.exe --download-only` | Псевдонім команди download |
| `Elyra-Launcher-x64.exe --dry-run` | Перевірити та звітувати без будь-яких змін |
| `Elyra-Launcher-x64.exe --silent` | Тихий режим Windows Installer |
| `Elyra-Launcher-x64.exe --no-launch` | Встановити, не відкриваючи застосунок |
| `Elyra-Launcher-x64.exe --cleanup` | Видалити завантажений MSI після встановлення |
| `Elyra-Launcher-x64.exe --allow-insecure-http` | Дозволити дзеркало зі звичайним HTTP (не рекомендується) |
| `Elyra-Launcher-x64.exe --version` | Вивести версію лаунчера |
| `Elyra-Launcher-x64.exe help` | Показати вбудовану довідку |

Лаунчер записує завантаження до `%TEMP%\elyra-installer\` і зберігає там журнал
встановлення MSI — `install.log`. Під час встановлення з URL він автоматично
намагається отримати `<url>.sha256` ще до завантаження, тому погане дзеркало
відхиляється на ранньому етапі. Якщо контрольну суму не опубліковано, він
виводить обчислений геш і покладається на підпис MSI та перевірку Windows
Installer; передайте `--require-checksum`, щоб зробити контрольну суму
обов’язковою. За замовчуванням завантаження здійснюються лише через HTTPS;
`--allow-insecure-http` призначений для довірених локальних або ізольованих
дзеркал.

## 4. Перший запуск

Під час першого запуску Elyra створює локальну базу даних і заповнює невелику
демонстраційну поштову скриньку, щоб інтерфейс ніколи не був порожнім.

Модальне вікно початкового налаштування пропонує три варіанти:

1. **Створити обліковий запис** — зареєструйтеся на сервері Elyra. Введіть
   URL-адресу сервера, якщо вона не типова. Пароль має містити щонайменше
   12 символів.
2. **Я вже маю обліковий запис** — увійдіть за наявним обліковим записом Elyra.
3. **Продовжити в автономному режимі** — пропустіть реєстрацію в хмарі.
   Локальна поштова скринька, демонстраційні повідомлення, теми, чернетки та
   лабораторія безпеки залишаються доступними. Облікові записи IMAP можна
   додати пізніше.

«Продовжити в автономному режимі» зберігає прапорець у `localStorage`
вебперегляду (`elyra-onboarding-skipped`), щоб модальне вікно не з’являлося при
кожному запуску. Пізніше можна під’єднатися через **Налаштування → Elyra Cloud →
Під’єднати обліковий запис**.

### URL-адреса сервера

Для локальної розробки типовою є `http://127.0.0.1:8787`. Для розгорнутого
сервера введіть публічну базову адресу API **включно з** `/api` і **без** кінцевої
похилої риски, наприклад:

```text
https://mail.example.com/api
```

Порядок визначення адреси описано в
[Довідник конфігурації → URL API десктопу](reference/configuration.md#desktop-api-url).
Щоб перевірити власний сервер після розгортання, скористайтеся
[контрольним списком перевірки виробничого розгортання](deploy/VERIFY.md).

## 5. Огляд за п’ять хвилин

1. **Вхідні** — демонстраційні повідомлення з’являються у списку листів.
   Швидкий фільтр дозволяє перемикатися між «Усі», «Непрочитані», «Із зіркою»
   та «З вкладеннями».
2. **Відкрити повідомлення** — клацніть рядок. У області читання відображаються
   тіло листа, метадані та картки вкладень. На панелі інструментів можна
   позначити зіркою, відповісти, переслати, позначити як непрочитане,
   архівувати, позначити як спам або перемістити до кошика.
3. **Створення листа** — клацніть **Написати лист**, виберіть обліковий запис
   для надсилання, якщо він є, і надішліть. Без поштового облікового запису
   Elyra спробує налаштування SMTP, задані в оточенні, а потім — ретранслятор
   Elyra Cloud, якщо ви увійшли в систему.
4. **Під’єднати справжню поштову скриньку** — відкрийте
   **Налаштування → Поштові облікові записи → Додати обліковий запис**.
   Виберіть готові налаштування провайдера, введіть адресу та пароль
   застосунку, а потім скористайтеся кнопками **Перевірити з’єднання** та
   **Синхронізувати**.
5. **Налаштуйте під себе** — змініть тему, акцент, щільність, підпис та ім’я,
   що відображається, у розділах **Налаштування → Вигляд** і
   **Налаштування → Ідентичність**.

## 6. Під’єднання поштової скриньки

Elyra 0.4.0 підтримує облікові записи IMAP/SMTP з TLS або STARTTLS. Десктопна
збірка також підтримує вхід до IMAP Gmail/Outlook через OAuth 2.0 Authorization
Code + PKCE, коли налаштовано ідентифікатор клієнта. Для SMTP досі потрібен
пароль застосунку або релей Elyra. Див. [OAuth провайдерів](oauth.md).

| Провайдер | Готові налаштування | Примітки |
| --- | --- | --- |
| Gmail | `imap.gmail.com`, `smtp.gmail.com` | Потрібна двофакторна авторизація та пароль застосунку |
| Outlook / Microsoft 365 | `outlook.office365.com`, `smtp.office365.com` | Використовуйте пароль застосунку, якщо його вимагає ваша організація (tenant) |
| iCloud Mail | `imap.mail.me.com`, `smtp.mail.me.com` | Використовуйте пароль, створений спеціально для застосунку |
| Yahoo Mail | `imap.mail.yahoo.com`, `smtp.mail.yahoo.com` | Створіть пароль застосунку |
| Fastmail | `imap.fastmail.com`, `smtp.fastmail.com` | Рекомендується пароль застосунку |
| Proton Mail | `127.0.0.1` | Потрібен локально запущений Proton Mail Bridge |
| Власний | Будь-який хост | Введіть сервери IMAP і SMTP, порти та режим безпеки |

Паролі зберігаються в диспетчері облікових даних Windows, а не в SQLite. Повний
покроковий опис див. у [посібнику користувача → Поштові облікові записи](user-guide.md#mail-accounts).

## 7. Де зберігаються ваші дані

| Дані | Розташування |
| --- | --- |
| База даних локальної поштової скриньки | `%LOCALAPPDATA%\com.elyra.desktop\elyra.sqlite3` |
| Файли журналу/WAL SQLite | Той самий каталог |
| Сеанс Elyra Cloud і паролі IMAP | Диспетчер облікових даних Windows, служба `com.elyra.desktop` |
| Параметри інтерфейсу | Таблиця SQLite `settings`, з резервним збереженням у `localStorage` у попередньому перегляді в браузері |
| Завантажені інсталятори | `%TEMP%\elyra-installer\` |

Точний шлях до бази даних завжди показано в **Налаштування → Діагностика**. На
тій самій панелі наведено версію SQLite, розмір бази, доступність сховища ключів
та кількість поштових скриньок.

### Резервне копіювання

Закрийте Elyra, а потім скопіюйте `elyra.sqlite3` разом з усіма файлами `-wal` і
`-shm` у безпечне місце. База даних містить метадані та тіла повідомлень,
отримані з IMAP, а також локальні налаштування. Вона **не** містить паролів зі
сховища ключів. Резервна копія без сховища ключів не зможе надсилати чи
синхронізувати листи, доки паролі не буде введено повторно.

### Скидання

- **Налаштування → Дані → Скинути демонстраційну скриньку** відновлює початкові
  демонстраційні повідомлення.
- Видалення файлу SQLite починає роботу з повністю чистого стану. Спочатку
  закрийте Elyra. Це також видаляє локальні чернетки та кешовані повідомлення.
- Використовуйте **Налаштування → Elyra Cloud → Вийти**, щоб видалити сеанс
  хмари зі сховища ключів, не змінюючи поштову скриньку.

## 8. Оновлення

- **Користувачі лаунчера:** запустіть `Elyra-Launcher-x64.exe` знову. Він
  завантажить найновіший MSI і встановить його поверх поточної версії.
- **Користувачі інсталятора:** завантажте найновіший файл зі сторінки випусків і
  запустіть його. Windows Installer виконає оновлення.
- **Команда лаунчера:** `Elyra-Launcher-x64.exe update`.

Ваша локальна поштова скринька та записи у сховищі ключів зберігаються після
оновлень. Примітки до випусків розташовані на сторінці випусків GitHub і на
вкладці **Зміни** в застосунку.

<a id="9-uninstall"></a>

## 9. Видалення

Скористайтеся Windows **Налаштування → Програми → Elyra → Видалити** або
виконайте:

```powershell
.\Elyra-Launcher-x64.exe uninstall
```

Видалення прибирає застосунок, але навмисно зберігає базу даних локальної
поштової скриньки, щоб випадкове видалення не знищило листи. Лаунчер може
виконати повне очищення за вас:

| Прапорець | Призначення |
| --- | --- |
| `--remove-data` (або `--purge`) | Видалити `%LOCALAPPDATA%\com.elyra.desktop` і записи Elyra в диспетчері облікових даних Windows |
| `--backup-data <folder>` | Скопіювати файли бази даних до теки перед тим, як `--remove-data` їх видалить |
| `--product-code <GUID>` | Видалити певний зареєстрований продукт Windows Installer |
| `--dry-run` | Показати, що буде видалено, без будь-яких змін |

```powershell
.\Elyra-Launcher-x64.exe uninstall --backup-data C:\Elyra-backup --remove-data
```

Без `--remove-data` локальні дані можна видалити вручну:

```text
%LOCALAPPDATA%\com.elyra.desktop
```

Записи диспетчера облікових даних, створені `keyring-rs`, містять маркер
`com.elyra.desktop`; лаунчер автоматично видаляє їх лише з `--remove-data`.
