The product

An email workspace that respects the machine it runs on.

Most mail clients treat the browser as the product and your computer as a cache. Elyra reverses that. The desktop app owns the data, the Rust core owns the logic, and the interface stays out of the way.

01

The mailbox engine is Rust, not JavaScript

Filtering, search, folder mutations, bulk actions, drafts, snooze, export and statistics are Tauri commands backed by SQLite. The webview only renders what the core returns.

list_mailboxbulk_update_messagesexport_mailbox
02

Private by architecture

Messages, settings and security events live in a local database. Secrets are validated by the Rust crypto layer. Cloud sync is optional, never the default.

03

Search that keeps up

Instant quick filters for unread, starred and attachments. Search across senders, subjects, previews and bodies without shipping a single message to a search service.

04

Built for long sessions

Four themes, accent colours, density controls, a command palette and a reading pane designed for wide screens. Reduce-motion support is one toggle away.

05

Your local workspace, portable

Export your mailbox as a readable JSON backup. Reset the demo data, inspect the SQLite path and check the exact engine version from the built-in diagnostics panel.

$ elyra --diagnostics engine   Rust + Tauri + SQLite storage  %LOCALAPPDATA%\com.elyra.desktop\elyra.sqlite3

Privacy, concretely

No mystery servers between you and your mail.

Elyra does not need an account to open a local workspace. The desktop build creates the database on first launch and keeps every mailbox decision on the device. When cloud features are enabled, the Rust bridge sends only what you explicitly ask for.

Questions

Good to know before you install.

Does Elyra need an account?

No. The desktop app opens a local workspace immediately. An Elyra account is only needed for optional cloud notifications and sync.

Where is my mail stored?

In a local SQLite database. On Windows it is usually %LOCALAPPDATA%\com.elyra.desktop\elyra.sqlite3; on Linux it lives under your XDG data directory, typically ~/.local/share/com.elyra.desktop/elyra.sqlite3. Settings → Diagnostics shows the exact path.

How large is the download?

The app itself is compact, and the exact installer size is listed on the release page. Tauri uses the WebView2 runtime that ships with Windows 10 and 11; the installer embeds a bootstrapper if the runtime is missing.

How do updates work?

When the release signing key is configured, Windows checks a signed feed in Settings → Updates, downloads the verified MSI or NSIS installer, and applies it with progress shown in the app. A failed check or bad signature leaves your current installation untouched. Linux builds are updated by replacing the checksummed AppImage or .deb.

Is Linux supported?

Yes. The x86_64 AppImage and .deb packages ship with SHA-256 checksums, and the repository includes a PKGBUILD and build guide. Linux keychain integration is still hardening, so cloud sign-in may be limited until a Secret Service backend is available.

What about Gmail and Outlook?

IMAP sync works today for Gmail, Outlook, iCloud, Yahoo, Fastmail, Proton Bridge and custom servers — passwords stay in the Windows Credential Manager. One-click OAuth with PKCE is the next milestone.

Windows showed a SmartScreen warning. Is that expected?

The release builds are not code-signed yet, so Windows may ask you to confirm the publisher. Choose “More info” → “Run anyway” only if you downloaded the file from this repository’s Releases page. You can also compare the published SHA-256 checksum before installing.

Can I uninstall cleanly?

Yes. Use Windows Settings → Apps → Elyra, or the portable launcher's uninstall --dry-run to preview what it would remove. Data and keychain entries are kept by default; add --remove-data (with optional --backup-data) only when you want a full reset.
